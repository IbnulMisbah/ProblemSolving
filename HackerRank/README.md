## 🚀 Getting Started

### Prerequisites
- C compiler (gcc)
- C++ compiler (g++)
- Python 3.x

### Compiling & Running

**C Solutions:**
```bash
gcc -o output filename.c
./output
```

**C++ Solutions:**
```bash
g++ -o output filename.cpp
./output
```

**Python Solutions:**
```bash
python3 filename.py
```
